# WaterGAP3 Exercises: A Practical Guide

This guide introduces the main exercises for setting up, preparing input data, and running the WaterGAP3 hydrological model. Follow the exercises in the order below to understand the workflow from installation to model execution.

## 1. Setup and Installation
[WaterGAP3 Setup](https://hydrosimul.github.io/Web/watergap3/WG3_Setup.html)

Install and configure the required software, including R, RStudio, Git, and the WaterGAP3 packages. Learn how to configure GitHub access and verify the installation.

## 2. Getting Started
[Getting Started with WaterGAP3](https://hydrosimul.github.io/Web/watergap3/WG3_GetStart.html)

Learn how to configure the model, run simulations for individual continents, use initial model states, and perform multi-year or global simulations.

## 3. File Input and Output
[File I/O](https://hydrosimul.github.io/Web/watergap3/WG3_File_IO.html)

Explore how WaterGAP3 stores and loads data using binary file formats. Practice writing matrices, loading parameter vectors, and converting model data into raster format for visualization.

## 4. Meteorological Pre-Processing
[Meteorological Pre-Processing](https://hydrosimul.github.io/Web/watergap3/WG3_PreMeteo.html)

Prepare the meteorological inputs required by the model. The exercises cover calculating net longwave radiation when needed and generating Leaf Area Index (LAI) data.

## 5. Water-Use Pre-Processing
[Water-Use Pre-Processing](https://hydrosimul.github.io/Web/watergap3/WG3_PreWateruse.html)

Learn how to derive water-use inputs from raw data, including net withdrawals from surface water and groundwater and reservoir water demand.

## 6. HydroParam Preparation
[HydroParam Preparation](https://hydrosimul.github.io/Web/watergap3/WG3_PreHydroParam.html)

Prepare the static input parameters required by WaterGAP3, including grid-cell characteristics, river network topology, water bodies, land cover, soil properties, and other physiographical parameters.

## Learning Objective

By completing these exercises, you will gain practical experience with the WaterGAP3 workflow, from software installation and input-data preparation to executing simulations and processing model outputs.
